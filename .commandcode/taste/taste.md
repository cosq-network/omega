# Taste

- Wants the Omega OS to be maximally compatible with the Linux kernel: parallel processing and related ABIs, user/roles and file permission systems, and the binary ABI (static libraries, shared objects, executables built on Linux) should all work on Omega. Confidence: 0.9
- Wants every feature/subsystem to support all three target architectures — x86_64, AArch64, and RISC-V (64-bit) — not just one. Confidence: 0.95
- Default filesystem for the Omega system is ext4. Confidence: 0.85
- Prefers implementations that follow industry standards/protocols (e.g., standard VGA display, VirtIO, plug-and-play storage standards) rather than custom protocols. Confidence: 0.75
- Accepts LGPL-licensed third-party components (e.g., TinyCC) as separately-shipped distro binaries, keeping the Apache-2.0 kernel/tree clean. Confidence: 0.6
